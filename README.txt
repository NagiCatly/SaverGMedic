CAMPUS MEDIC - NSTP FIRST-AID RESCUE

RUN
1. Open this OOP folder in a terminal.
2. Compile with: javac *.java
3. Start with: java Main

TITLE MENU
- 1: Tutorial Mode
- 2 or ENTER: Start Real Game
- LEFT / RIGHT or A / D: Choose player skin

CONTROLS
- W / A / S / D or Arrow Keys: Move
- SHIFT: Run
- E: Interact, talk, treat, or restock
- 1 / 2 / 3: Select a dialogue answer
- P / ESC: Pause
- G: Open/close the Tutorial Guide during Tutorial Mode

TIME
- Real game starts with 8:00 minutes.
- Completing each level adds 1:30 minutes.

ASSETS
Keep MAPS and CHARACTER folders inside this OOP folder. Run java Main from this folder.
